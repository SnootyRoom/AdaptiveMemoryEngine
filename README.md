# AdaptiveMemoryEngine

## Курсовой проект по предмету "Программирование на C++" <br> по теме: Адаптивный аллокатор для игровых сущностей с политиками памяти

**Передо мной поставлены следующие задачи: **

- Реализовать иерархию аллокаторов (Pool, Stack, Free‑list) с переключением стратегии в зависимости от размера и времени жизни объектов (частицы, снаряды, пулы врагов).
- Совместимость с std::pmr, интеграция в std::pmr::vector.
- Использовать std::unique_ptr с кастомными делитерами для возврата памяти в пул.
- Написать бенчмарк в игровом цикле (1000+ объектов) и сравнить с системным аллокатором.
